# 医疗数据离群值检测系统

## 项目简介

本项目是一个基于MVC架构的医疗数据离群值检测系统，集成了多种机器学习算法（孤立森林、LOF、One-Class SVM），用于检测医疗数据中的异常值，并结合医学规则进行验证。

## 系统架构

采用MVC（Model-View-Controller）三层架构：

```
┌─────────────────────────────────────────┐
│              View 视图层                 │
│         (templates/index.html)           │
│    - 前端界面展示、数据可视化             │
└─────────────────────────────────────────┘
                    ↑↓
┌─────────────────────────────────────────┐
│           Controller 控制层              │
│    (controllers/analysis_controller.py)  │
│    - 业务逻辑处理、算法调度               │
└─────────────────────────────────────────┘
                    ↑↓
┌─────────────────────────────────────────┐
│             Model 模型层                 │
│  - models/data_processor.py   数据处理   │
│  - models/outlier_detector.py 离群值检测 │
│  - models/clinical_validator.py 医学验证 │
└─────────────────────────────────────────┘
```

## 核心功能

### 1. 离群值检测算法

| 算法                             | 特点               | 适用场景           |
| ------------------------------ | ---------------- | -------------- |
| **孤立森林 (Isolation Forest)**    | 基于随机树路径长度，适合高维数据 | 大规模数据、全局异常检测   |
| **LOF (Local Outlier Factor)** | 基于局部密度对比         | 密度不均匀数据、局部异常检测 |
| **One-Class SVM**              | 基于边界学习           | 小样本数据、边界检测     |

### 2. 自适应阈值

系统采用自适应阈值方法，根据数据分布自动确定离群值：

- **IQR方法**：Q3 + k×IQR
- **标准差方法**：均值 + k×标准差
- **百分位数方法**：Top k%

### 3. 医学规则验证

结合临床规则库验证检测结果：

- 医学合理离群值
- 医学可疑离群值
- 临床符合性评估

### 4. 数据可视化

- 模型性能对比图表
- 离群值检测结果展示
- 医学验证结果可视化
- 大数据/小数据指标对比

## 使用说明

### 1. 选择分析类型

- **快速分析**：使用200条样本，适合快速预览

- **所有模型**：同时运行三种算法进行对比

- **局部离群因子 (LOF)**：适合局部密度异常的检测

### 3. 查看结果

系统会展示：

- 总样本数和异常样本数
- 各算法的检测时间和离群值数量
- 模型性能对比（准确率、F1分数）
- 医学符合性验证结果
- 数据指标对比图表

## 常见问题

### Q1: 为什么不同算法检测到的离群值数量不同？

A: 不同算法基于不同的原理（树结构、密度、边界），对数据的敏感度不同，因此检测到的离群值数量和具体样本会有差异。

### Q2: 如何选择最优算法？

A:

- 高维数据 → 孤立森林
- 密度不均匀数据 → LOF
- 需要明确边界 → One-Class SVM
- 不确定 → 使用所有模型对比

### Q3: 自适应阈值和固定contamination有什么区别？

A: 自适应阈值根据数据实际分布确定，更灵活；固定contamination强制指定异常比例，可能不符合数据实际情况。
